# SpendWise - Expense Tracker

## CS310 Mobile Application Development

**Group Number:** 2

## Project Description

SpendWise is a mobile expense tracking application developed using Flutter and Dart.

The application helps users manage their daily expenses, track spending habits, and visualize their financial activity through simple charts and summaries.

## Core Features

- Add, edit, and delete expenses
- Organize expenses by category
- View total and recent expenses on a dashboard
- Track monthly spending
- Visualize spending with charts
- Store expense data locally
- Simple and user-friendly interface

## Technologies

- Flutter
- Dart
- Material 3
- Local Database (SQLite or Hive)
- Git and GitHub
